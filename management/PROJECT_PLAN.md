\## Repository Workflow



1\. Update the `main` branch before starting a task.

2\. Create a new branch for each task.

3\. Make changes only in the task branch.

4\. Commit and push the changes.

5\. Create a Pull Request to `main`.

6\. At least one team member must review and approve the Pull Request.

7\. The Project Manager verifies the Pull Request and performs the final merge.

8\. Delete the branch after it has been merged.



\## Project Structure



\- `src/` - Compiler source code

\- `docs/` - Project documentation

\- `design/` - Models, diagrams and architecture

\- `presentation/` - Presentation materials

\- `management/` - Project planning and management
